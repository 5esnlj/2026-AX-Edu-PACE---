# MariaDB 실행 검증 결과

검증일: 2026-11-21
실행 환경: MariaDB 11.8.6-MariaDB-ubu2404, 별도의 일회용 Docker 컨테이너, 외부 네트워크/호스트 공개 포트 없음.
결과: **64개 검증 통과**. 최종 `01_create_tables.sql` 전체를 빈 DB에서 실행하여 20개 테이블을 생성했습니다.

권한 검증은 `02_authorized_queries.sql`에 실제 제공한 쿼리를 가상 사용자/클래스/자료에 실행한 결과입니다. 운영 웹앱의 API를 수정하거나 검증한 것은 아닙니다. 진단 테스트 문항은 제약 검증용 최소 가상 자료이며, 실제 시험지나 전체 루브릭 채점 검증 결과가 아닙니다.

틀린 연결/잘못된 값 삽입은 외래키(1452), CHECK(4025), 중복 키(1062) 오류로 거부되는지 확인했습니다. 각 실패 검증은 트랜잭션으로 격리했습니다.

서버 구현이 필요한 사항: 세션 인증, 생성/수정 권한, 초대 동시 처리, 진단 완결성·채점, 배포 후 불변, 제출 채점·순번 할당, 저장소 파일 제공, 암호화 키 관리. DDL/조회 검증 통과가 이 API 기능의 구현 완료를 뜻하지는 않습니다.
