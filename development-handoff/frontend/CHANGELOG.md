# 2026-11-21 API 연동 변경

- 고정 예시 사용을 제거하고 `/api/v1` HTTP mock을 기본값으로 변경했습니다.
- 세션 로그인/복원/로그아웃, 서버 클래스 선택, 진단 및 가입 미완료 안내를 추가했습니다.
- wire DTO와 화면 DTO를 분리하고 순수 변환 함수를 추가했습니다.
- 학생용 임시 `/student/classes/{id}/home`를 공통 dashboard 경로로 교체했습니다.
- 교사 자료 목록을 `/sources`로 연결하고 다른 교과 섹션을 제거했습니다.
- 초급 미달/진단 미완료 집계·필터, 선택 영역, 최초 정답 수/현재 오답 구분을 반영했습니다.
- 학생 문항을 미시작/진행 중/완료/재풀이로 구분하고, 잘못된 retryCount 표시를 currentWrongCount로 교체했습니다.
- 고정 사용자·클래스·사이드바 수준·검토 대기 수를 서버 응답으로 대체했습니다.
- 204 처리, 서버 오류, CSRF, 사용자 헤더, FormData, ETag 조회를 지원하도록 HTTP client를 변경했습니다.
- 로딩/오류/빈 상태를 추가하고 미구현 기능은 비활성화 및 안내했습니다.
- adapter/client 테스트 9개 및 별도 테스트 TypeScript 설정을 추가했습니다. 새 npm 의존성은 추가하지 않았습니다.
- 교사/학생 생성·자료 상세·풀이 등 전체 업무 화면을 구현한 변경은 아닙니다.
