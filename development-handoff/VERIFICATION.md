# FE·API 수정본 검증 결과

검증일: 2026-11-21. API 버전1.1.0. 모든 사용자·자료·문항은 가상 데이터입니다.

| 검사 | 결과 | 확인한 범위 |
|---|---|---|
| API HTTP 테스트 | **31개 통과** | 기존25개 + FE 계약 회귀6개. 인증·권한·진단·배포·풀이·새 응답 필드 |
| 캡처 응답 스키마 | **53개 통과** | 실제 mock HTTP 응답을 최신 OpenAPI와 비교. 오류 응답 포함 |
| FE adapter/client 테스트 | **9개 통과** | 교과/수준 변환, 최초 정답 수·최신 오답·진행률, CSRF, FormData,204,ETag,요청 헤더·오류 |
| TypeScript·Vite 빌드 | **통과** | `npm run build` |

| Chromium 브라우저 연동 | **8개 시나리오 통과** | 실제 Vite proxy → Python mock 요청. JavaScript 런타임 오류0개 |

## 브라우저에서 확인한 동작

1. 교사 로그인 → 서버의 클래스·학생 이름·중국어 표시, 초급 미달/진단 미완료 필터.
2. 수학 교사의 자료 목록에는 수학 원본만 표시.
3. 로그아웃 후 과학 교사로 로그인하면 같은 반에서도 과학 원본만 표시.
4. 학생 로그인 → 생활한국어/수학 영역 변경 → 해당 수준 표시, 새로고침 후 세션 복원.
5. 실제 mock API에 답안을 제출한 뒤 화면 확인: 제출1/3 → ‘푸는 중’33%, 최초 전체 제출+오답 → ‘다시 풀기’100%, 정답 재풀이 → ‘완료’. 첫 정답 수2/3과 최신 정답 수3/3은 별도로 유지.
6. 대시보드 통신 실패를 주입하면 오류 표시, 연결 복구 후 ‘다시 불러오기’로 회복.
7. 진단 미완료 학생은 진단 필요 안내를 받고 학습 대시보드에 들어가지 않음.
8. 클래스 미가입 학생은 클래스 참여 필요 안내를 받음.

결과 원문은 `browser-results.json`, 확인 화면은 `screenshots/`에 있습니다. 화면을 직접 확인했지만 Figma 캔버스와 픽셀 단위로 비교하지는 않았습니다. 첫 브라우저 시도는 테스트의 로그인 선택상자 탐색 조건이 맞지 않아 중단되었고, 선택자를 수정한 재실행에서8개 시나리오가 통과했습니다.

## 재현

API와 FE 검사 명령은 `시작하기.md`에 있습니다. 브라우저 검증은 선택 사항이며 Python Playwright와 Chromium이 추가로 필요합니다. `verify_browser.py`는 localhost/127.0.0.1의 mock 모드인지 검사한 다음 가상 답안을 제출합니다. 매번 API를 새로 시작해 초기 상태에서 실행하세요.

```bash
python -m pip install playwright
python -m playwright install chromium
python verify_browser.py
```

이 환경에서는 설치된 Chromium을 사용해 `python verify_browser.py --browser /usr/bin/chromium`으로 실행했습니다. Python3.12, Node24.19, Vite5.4.21을 사용했습니다. API 테스트 의존성 버전은 `api/requirements-tested.txt`에 있습니다.

## 이번에 검증하지 않은 것

- 실제 MariaDB의 트랜잭션·동시성·재시작 후 영속 저장.
- 실제 Solar 요청·과금·모델 응답 품질, PDF 추출과 비공개 파일 저장.
- 공식 진단 문제·음원과 교육 담당자의 채점/변환 품질 검수.
- 아직 조립하지 않은 업무 화면, 학교 운영 환경의 배포·접근성·부하·백업 복원.

mock은 검증용 계약 구현이며 운영 백엔드가 아닙니다. 원본 소스와 기존 DDL/DML은 보존했습니다. 이번 결과물은 별도 파일 묶음이며 GitHub나 사용자 PC에는 자동 적용되지 않습니다.
