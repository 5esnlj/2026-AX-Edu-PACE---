# API mock 검증 결과

검증일: 2026-11-21 · API 1.1.0 · Python 3.12.14 · DB/Solar 없는 가상 데이터 테스트

- 자동 HTTP 테스트: **31개 통과**, 실패0.
- 최종 API 동작: **41개**(37개 경로).
- 실제 HTTP 요청에서 캡처한 mock 예시: **53개**, 모두 OpenAPI 응답 스키마 검증 통과.
- 화면 매핑: 첨부 HANDOFF의19개 고유 Figma 프레임 링크.

인증 역할·CSRF·교사 자기교과/클래스·학생 본인배정·미배포 접근 제한, 초대 역할/만료/사용횟수, 진단 이어하기/중복/70개문항/10파트+5종합/과락, 검토후수정해제/버전충돌/배포, T/F와4지선다, 최초점수/정답개수/재풀이/요청키재전송, PDF업로드·파일접근, 취소된 고정키의 대체 사용 금지를 검증했습니다.

실행: `python -m unittest -v test_api test_frontend_contract`. 세부 테스트는 test_api.py와 test_frontend_contract.py에 있으며, 시나리오 범위는 TEST_PLAN.md를 참고합니다. examples.json은 capture_examples.py로 재생성할 수 있습니다.

추가 6개 회귀 검사는 클래스명, 진단 미완료와 과락 구분, 비활성 학생 집계 제외, 원본·학생별 자료 카드 구분과 단원명, 재풀이 후 최초 점수 보존, 진단 영역 변경으로 교과 접근 범위가 넓어지지 않음을 확인했습니다. 상위 폴더의 통합 검증 보고서에는 FE 테스트와 브라우저 검증을 별도로 기록합니다.

실제 MariaDB 트랜잭션/다중프로세스동시성, 실제 Solar 응답, PDF 추출·바이러스검사, 공식진단문항, Figma 캔버스의 시각 대조는 이 API 테스트에서 검증하지 않았습니다. 격리된 ASGI TestClient 검증이며 운영 서비스 구현 완료를 뜻하지 않습니다. 실행 환경의 sandbox 내 TestClient 제약 때문에 가상 요청 검증은 권한 확장된 로컬 프로세스로 실행했고 외부 서비스에는 요청하지 않았습니다.
