## A. 서윤이 할 일

1. **피그마 공유**
   피그마 파일을 열고 오른쪽 위 **Share** → 개발자 이메일 입력 → 권한 **can view** → 보내기.
2. **이 zip 파일 보내기**
   카톡이나 메일로 zip을 그대로 보냅니다.
3. **같이 보낼 메시지**
   > 프론트 화면 시안이랑 AI용 설명서예요. zip은 프로젝트 맨 위 폴더에 풀어주시고, `시작하기.md`의 B부터 봐주세요. HANDOFF.md의 "보여줄 것"이 지금 서버에서 주는 데이터와 맞는지 확인 부탁드려요.
4. **15분 화면 공유 잡기** (C 참고)

## B. 개발자가 할 일

### 1단계 · 파일 넣기
- zip을 **프로젝트 맨 위 폴더**에 풉니다. (`src/` 폴더가 이미 있으면 안쪽 파일만 합쳐 넣기)
- 쓰는 도구에 맞춰:
  - **Claude Code:** `CLAUDE.md`가 맨 위에 있으면 자동으로 읽습니다. 끝.
  - **Cursor 등:** `CLAUDE.md` 내용을 `AGENTS.md`로 복사해 둡니다.
- 전역 CSS로 `src/styles/tokens.css`를 앱 시작 파일에서 한 번 불러옵니다.

### 2단계 · 피그마 연결 (선택이지만 추천)
AI가 피그마 화면을 직접 읽고 코드를 짤 수 있게 됩니다.

**Claude Code**
```bash
claude mcp add --transport http figma https://mcp.figma.com/mcp
```
→ Claude Code를 다시 열고 `/mcp` 입력 → `figma` 선택 → **Authenticate** → 브라우저에서 **Allow Access**
→ 다시 `/mcp`로 연결됐는지 확인

**Cursor / VS Code**
MCP 설정에 서버 주소 `https://mcp.figma.com/mcp`를 추가하고, 로그인 창이 뜨면 허용합니다.

> 피그마 파일 공유를 받은 계정으로 로그인해야 화면을 읽을 수 있습니다.

### 3단계 · AI에게 시키는 순서
한 번에 다 시키지 말고 아래 순서로 나눠서 시키면 결과가 훨씬 안정적입니다.

| 순서 | AI에게 이렇게 말하기 |
|---|---|
| ① 부품 | "HANDOFF.md 2장의 '반복해서 쓰는 부품'을 `src/components/`에 먼저 만들어줘. 색·크기는 tokens.css 변수만 써." |
| ② 틀 | "상단바와 사이드바(교사용·학생용)를 만들고, 지금 보는 메뉴 표시가 되게 해줘." |
| ③ 화면 | "HANDOFF.md의 교사 02 화면을 만들어줘. 피그마는 이 링크 참고: (HANDOFF.md에 있는 node-id 링크)" → 화면 하나씩 반복 |
| ④ 예시 데이터 | "화면에 보이는 예시 데이터는 `src/mocks/`로 빼줘." |
| ⑤ 서버 연결 | "우리 백엔드의 (API 이름)을 `src/api/`에 함수로 만들고, 교사 02 화면이 mocks 대신 이걸 쓰게 바꿔줘." |
| ⑥ 점검 | "CLAUDE.md 5장의 점검 명령을 돌려서 하드코딩 남은 거 고쳐줘." |

**화면 만드는 추천 순서:** 로그인 → 교사 01·02 → 학생 02·03 → 자료(교사 03~05, 학생 04~05) → 문항(교사 06~08, 학생 06~08) → 수준·진단(교사 09, 학생 01·09)

### 4단계 · 기존 기능 살리기
- **교사 05 자료 검토**, **학생 05 자료 보기**는 이미 만든 "자료 변환 창" 기능을 그대로 쓰고 **겉모습만** 새 디자인으로 바꿉니다.
- AI에게: "기존 자료 변환 기능 코드는 건드리지 말고, 화면 껍데기만 HANDOFF.md 교사 05 모양으로 바꿔줘."

## C. 둘이 함께

### 처음 한 번 · 15분 화면 공유
1. 서윤이 피그마 오른쪽 위 ▶(프레젠테이션)으로 로그인부터 클릭하며 흐름을 보여줍니다.
2. 개발자가 HANDOFF.md 5장 "아직 정해지지 않은 것"을 같이 보고, 지금 정할 수 있는 건 정합니다.
3. "보여줄 것" 중 서버에 없는 데이터가 있으면 메모해 둡니다.

### 디자인을 고치고 싶을 때
1. **서윤:** Claude와 대화하며 피그마를 고칩니다.
2. **서윤:** Claude에게 "바뀐 내용 HANDOFF.md에 반영해줘"라고 해서 새 HANDOFF.md를 받습니다.
3. **개발자:** 새 HANDOFF.md로 교체하고, AI에게 "HANDOFF.md에서 바뀐 ○○ 화면 다시 맞춰줘"라고 시킵니다.

> 색이나 둥글기처럼 전체에 걸친 변경은 `tokens.css` 값만 바꾸면 모든 화면에 한 번에 반영됩니다. 하드코딩을 막는 이유가 이거예요.

### 막혔을 때 체크
- AI가 색을 직접 써 넣었다 → "CLAUDE.md 2장 규칙 지켜서 다시 해줘"
- 화면이 피그마와 다르다 → 해당 화면의 피그마 링크를 다시 주고 "이 화면과 비교해서 다른 점 고쳐줘"
- 서버 데이터 이름이 HANDOFF.md와 다르다 → 서버 이름이 기준. HANDOFF.md는 화면 기준 설명이라 이름은 바꿔도 됨
