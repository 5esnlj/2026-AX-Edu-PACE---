# DML 초안 검증 메모

검증일: 2026-11-21
환경: MariaDB 11.8.6-MariaDB-ubu2404, 외부 네트워크/공개 포트 없는 일회용 컨테이너.

- 기존 20개 테이블 DDL을 그대로 생성한 뒤 **SQL 블록 88개 모두 PREPARE 성공**. 이름 있는 매개변수는 검증 시 위치 매개변수(?)로 치환했습니다.
- 진단 가상 문항 70개, 5영역×2파트의 총배점100 및 난도별 판정문항2개 구성을 확인했습니다.
- 문서의 채점 INSERT로 파트10행, 영역종합5행, 완료 상태 저장을 확인했습니다.
- 40점 중급/70점 고급 경계, 높은 점수여도 초급 판정 실패 시 초급 미달, 중급/고급 판정 미통과 시 하향을 확인했습니다.
- 한 파트가30미만이면 종합 합계가100이어도 초급, 파트 초급 미달을 종합에 자동 전파하지 않는 확정 규칙을 확인했습니다.
- 첫 문항만 제출했을 때 최초 성적NULL 유지, 모든 문항 최초 제출 후10점 확정, 재풀이 정답 후에도 최초10점 유지, 재풀이수1회/0회를 확인했습니다.

문법 검증과 위 가상 데이터 흐름의 실행 검증입니다. 인증·교사 승인·초대 동시성·모든 권한 분기·Solar 호출·파일 제공·실제 웹앱을 구현하거나 통합 검증한 결과는 아닙니다. 문서의 서버 분기와 트랜잭션 전제를 함께 구현해야 합니다. 실제 사용자 DB에는 실행하지 않았습니다.

검증용 컨테이너와 가상 데이터는 검증 후 제거했습니다.
