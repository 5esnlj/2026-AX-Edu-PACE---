# 가나다계단 프론트엔드 화면 설명서

AI 코딩 도구에 "HANDOFF.md 보고 ○○ 화면 만들어줘"라고 시키는 용도의 설명서입니다.
디자인 값은 `src/styles/tokens.css`(원본 `tokens/global.json`), 코딩 규칙은 `CLAUDE.md`를 따릅니다. 이미 만든 부품은 `src/components/`에 있습니다(README 2장).

- **피그마 파일:** https://www.figma.com/design/WQfQ1Uoaa0E013X51QSavH
- **페이지:** "01 장면 흐름" → 섹션 "가나다계단 화면 흐름"
- **기준 화면:** 컴퓨터 웹, 너비 1440px
- **피그마 화면 바로가기:** 아래 표의 `node-id`를 파일 주소 뒤에 붙이면 됩니다.
  예) `https://www.figma.com/design/WQfQ1Uoaa0E013X51QSavH?node-id=10-51`
  Figma MCP를 연결했다면 이 주소를 AI에게 그대로 주면 화면을 읽어 옵니다.

> 화면 속 이름·숫자(아지즈, 3학년 2반, 8/10 등)는 모두 예시 데이터입니다. 실제로는 서버에서 받아야 합니다.

---

## 1. 전체 흐름

```
로그인
 ├─ 교사 → 클래스 목록 → 클래스 대시보드
 │                         ├─ 자료 제작: 자료 목록 → 새 자료 만들기 → 자료 검토 → [학생에게 배포]
 │                         ├─ 문항 생성: 문항 목록 → 새 문항 만들기 → 문항 검토 → [학생에게 배포]
 │                         └─ 학생 수준
 └─ 학생 ─┬─ (첫 로그인) 진단 검사 → 클래스 목록
          └─ (두 번째부터) 클래스 목록 → 내 대시보드
                                         ├─ 받은 자료 목록 → 자료 보기
                                         ├─ 문항 목록 → 문제 풀기 → 결과 ─(다시 풀어볼래요)→ 문제 풀기
                                         └─ 진단 결과
```

## 2. 공통 틀

| 부품 | 어디에 | 내용 |
|---|---|---|
| **상단바** | 로그인 빼고 모든 화면 | 로고(심볼 + "가나다계단") · 검색창 · 알림 · 사용자 이름 · 프로필 원(이름 첫 글자, 레드) |
| **사이드바(교사)** | 클래스 안 교사 화면 | 클래스 선택(▾) · [+ 새 자료 만들기](레드 버튼) · 메뉴: 대시보드 / 자료 제작 / 문항 생성 / 학생 수준 · 아래쪽 "검토 기다리는 문항 N건" 카드 |
| **사이드바(학생)** | 클래스 안 학생 화면 | 클래스 선택(▾) · [▶ 문제 풀러 가기](레드 버튼) · 메뉴: 대시보드 / 받은 자료 / 내 문항 / 진단 결과 · 아래쪽 "내 수준"(듣기·읽기 막대) |

- 사이드바는 흰 바탕입니다. **지금 보는 메뉴만** 연한 분홍(`--card-red`) 바탕에 레드 글씨로 표시합니다.
- 클래스 목록, 진단 검사 화면에는 사이드바가 없고 상단바만 있습니다.

### 반복해서 쓰는 부품 (먼저 만들어 두고 재사용)

| 부품 | 모양 |
|---|---|
| `Button` | primary: 레드 바탕 흰 글씨 / secondary: 흰 바탕 연한 테두리 |
| `SummaryTile` | 연한 색 카드 + 제목(카드 제목색) + 큰 숫자 + 단위, 오른쪽 위 ↗ 원(누를 수 있을 때만) |
| `TableCard` | 흰 카드 + 그림자 + 제목/전체보기 + 머리행 + 구분선 있는 줄 |
| `FolderCard` | 위쪽 탭이 달린 연한 색 폴더 모양 카드(교과 · 제목 · 날짜 · 상태 배지) |
| `MenuCard` | 연한 색 큰 카드 + 색 제목 + 흰 아이콘 타일 + 오른쪽 아래 **파인 모서리** 안의 검은 ↗ 원 (클래스 목록) |
| `MaterialCard` | 자료 썸네일(디지털교과서 지면 미리보기): 위쪽 흰 지면(단원 번호 칸 · 단원 제목 · 본문 줄 · 그림 자리) + 아래 교과 · 자료 이름(최대 2줄) · 날짜 + 오른쪽 아래 파인 모서리 ↗. 교과별 색: 사회 파랑, 수학 노랑, 과학 초록, 국어 주황 |

**파인 모서리:** 카드 오른쪽 아래를 원 모양으로 파내고 그 안에 검은 ↗ 버튼(지름 56px)을 넣는 모양입니다. 버튼 중심은 모서리에서 안쪽으로 34px, 파낸 원은 반지름 38px(버튼보다 10px 큼), 파낸 곳과 카드 가장자리가 만나는 부분은 반지름 10px로 살짝 둥글게 이어집니다. 파낸 부분은 페이지 바탕색(`--color-background`)으로 보이게 합니다. 모양 그대로의 SVG 경로(오른쪽 아래 모서리 기준 150×150 상자, 카드 모서리가 (90,90)): `M 14.43 90 A 10 10 0 0 0 23.09 75.00 A 38 38 0 0 1 75.00 23.09 A 10 10 0 0 0 90 14.43 L 150 14.43 L 150 150 L 14.43 150 Z` — CSS `mask`로 카드에서 빼거나, 바탕색으로 카드 위에 겹쳐 그리면 됩니다.
| `LevelPill` | 초급 미달 / 초급 / 중급 / 고급 (색은 `--level-*`) |
| `ProgressBar` | 바탕 `--color-track`, 채움 `--color-text` |
| `Chip` | 필터·선택용. 선택됨: 차콜 바탕 흰 글씨 / 안 됨: 흰 바탕 테두리 |
| `UploadBox` | 점선 테두리 + 업로드 아이콘(레드) + "PDF 올리기" |

아이콘은 Lucide(https://lucide.dev)를 씁니다.

## 3. 수준 표기 (루브릭 기준)

화면에는 **초급 미달 / 초급 / 중급 / 고급** 네 가지만 표시합니다. 판정은 서버에서 하고, 프론트는 결과 글자만 받아서 `LevelPill`로 보여줍니다.

- **영역(국·수·사·과, 듣기, 읽기):** 100점 환산 40점 미만 초급, 40~70점 미만 중급, 70점 이상 고급
- **종합:** 듣기 + 읽기(200점 만점). 80점 미만 초급, 80~140점 미만 중급, 140점 이상 고급
- **생활한국어:** 기준 미정이라 지금은 "–"로 표시합니다.

## 4. 화면별 설명

표기: **보여줄 것** = 서버에서 받아 화면에 띄울 정보 / **누르면** = 버튼·줄을 눌렀을 때 동작.
주소(경로)는 제안이며, 기존 프로젝트 규칙이 있으면 그걸 따릅니다.

### 공통 01 · 로그인 — `node-id=11-148` · `/login`
- **구성:** 가운데 흰 카드: 로고 · "가나다계단" · [교사 | 학생] 탭 · 아이디 · 비밀번호 · [로그인]
- **누르면:** [로그인] → 교사면 교사 01, 학생이면 첫 로그인 여부로 학생 01(진단) 또는 학생 02로 이동

### 교사 01 · 클래스 목록 — `node-id=10-2` · `/teacher/classes`
- **보여줄 것:** 내가 참여 중인 클래스(내가 만든 것 + 공유받은 것) 이름
- **누르면:** 클래스 카드 → 교사 02 / [+ 클래스 추가] → 클래스 이름 입력창 / [초대 코드로 들어가기] → 공유받은 클래스 코드 입력창

### 교사 02 · 클래스 대시보드 — `node-id=10-51` · `/teacher/classes/:classId`
학생 중심 화면입니다. 화면 대부분이 학생 명단입니다.
- **보여줄 것:**
  - 맨 위: 클래스 이름, 학생 수
  - 요약 타일 4개: 전체 학생 수 / 초급 / 중급 / 고급 인원
  - 학생 명단 표: 이름, 모국어, 듣기·읽기·종합 수준, 최근 배포 문제 점수(막대 + "8 / 10", 안 풀었으면 레드 "아직 안 풂"), 틀린 문제 수(4개 이상이면 레드)
  - 사이드바 아래: 검토 기다리는 문항 수
- **누르면:** [학생 초대] → 초대 코드 창 / [클래스 공유] → 다른 선생님에게 공유 창 / 필터 칩(전체·초급·중급·고급) → 명단 거르기 / 학생 줄 → 학생 상세(화면 아직 없음)

### 교사 03 · 자료 목록 — `node-id=10-100` · `/teacher/classes/:classId/materials`
- **보여줄 것:** 만든 자료를 `MaterialCard` 썸네일로 4개씩 한 줄에 보여줌(교과, 단원 번호, 제목, 날짜). **내 교과 구역이 맨 위**, 다른 교과 구역은 아래. 교사의 교과는 가입할 때 정한 값
- **누르면:** [+ 새 자료 만들기] → 교사 04 / 썸네일 → 자료 검토·보기(만든 자료 보기 화면은 아직 없어서 지금은 교사 05로 연결)

### 교사 04 · 새 자료 만들기 — `node-id=10-139` · `.../materials/new`
- **구성:** PDF 올리기 칸 · 받을 학생 선택(칩, 여러 명) · [자료 만들기]
- 교과 선택은 없음(가입 시 정한 교과 사용)
- **누르면:** [자료 만들기] → PDF와 학생 목록을 서버로 보내고 → 교사 05

### 교사 05 · 자료 검토 — `node-id=10-189` · `.../materials/:materialId/review`
기존 "자료 변환 창" 기능을 그대로 쓰고, 화면만 새 디자인으로 바꿉니다.
- **보여줄 것:** 수준 묶음 탭(초급·중급·고급) · 학생 넘겨보기(‹ 이름 ›) · 원본 / 바뀐 자료 나란히
- **누르면:** [학생에게 배포] → 선택한 학생에게 배포(배포 후 이동할 화면은 미정)

### 교사 06 · 문항 목록 — `node-id=10-245` · `.../questions`
- **보여줄 것:** 만든 문항 묶음(제목 · 문항 수 · 상태: 검토 중 / 배포 완료)
- **누르면:** [+ 새 문항 만들기] → 교사 07 / 줄 → 만든 문항 보기(화면 아직 없음)

### 교사 07 · 새 문항 만들기 — `node-id=10-279` · `.../questions/new`
- **구성:** PDF 올리기 칸 · 받을 학생 선택 · [문항 만들기]
- **누르면:** [문항 만들기] → AI가 학생 수준별로 문항 생성 → 교사 08

### 교사 08 · 문항 검토 — `node-id=10-317` · `.../questions/:setId/review`
흐름: AI 생성 → 교사 검토 → 최종본 배포
- **보여줄 것:** 수준 묶음 탭 + 학생 넘겨보기 · 문항과 보기 · 정답 표시(연한 초록) · "1 / 10" 쪽수
- **누르면:** [수정] → 문항·답안 고치기 / [학생에게 배포]

### 교사 09 · 학생 수준 — `node-id=10-368` · `.../levels`
- **보여줄 것:** 탭 [교과별 | 듣기·읽기 | 종합]
  - 교과별 표: 이름 × 국어·수학·사회·과학·생활한국어 수준
  - 오른쪽 카드: 최근 배포 문제별 점수

### 학생 01 · 진단 검사 — `node-id=11-191` · `/student/diagnosis`
껍데기 화면만 있습니다. 문제 내용은 추후 연결합니다.
- **보여줄 것:** 진행 "3 / 20" + 진행 막대 · 영역 표시(듣기/읽기) · [▶ 듣기] · 문제 · 보기 4개
- **규칙:** 첫 로그인 때 한 번만. 중간에 나가면 다음 로그인 때 **답을 안 쓴 문제부터** 이어서
- **누르면:** [다음] → 다음 문제, 마지막이면 학생 02

### 학생 02 · 클래스 목록 — `node-id=11-237` · `/student/classes`
- **보여줄 것:** 참여 중인 클래스
- **누르면:** 클래스 카드 → 학생 03 / [초대 코드 입력] → 코드 입력창(선생님이 준 코드로 클래스 참여)

### 학생 03 · 내 대시보드 — `node-id=11-278` · `/student/classes/:classId`
- **보여줄 것:**
  - 인사말 "안녕하세요, (이름)!" + "오늘 풀 문제가 N개 있어요"
  - 할 일 카드 2개: 안 푼 문항(→[풀러 가기]) / 다시 풀 문제(→[다시 풀기])
  - 새로 받은 자료: 폴더 카드 3개(교과 · 제목 · 받은 날짜 · NEW 표시)
  - 내 문항 표: 문항 · 교과 · 진행 막대 · 상태(풀기 전 / 다시 풀 문제 N / 완료)
  - 사이드바 아래: 내 수준(듣기·읽기 등급 + 막대)
- **누르면:** [풀러 가기] → 학생 07 / 폴더 카드 → 학생 05 / "전체보기" → 각 목록

### 학생 04 · 받은 자료 목록 — `node-id=11-323` · `.../materials`
- **보여줄 것:** 교과 필터 칩 + 교과별 구역의 `MaterialCard` 썸네일(제목, 받은 날짜 또는 "새 자료")
- **누르면:** 썸네일 → 학생 05

### 학생 05 · 자료 보기 — `node-id=11-368` · `.../materials/:materialId`
기존 자료 보기 기능을 그대로 유지합니다.
- **구성:** 도구 버튼(듣기 · 글자 크기 · 번역본 · 단어장 · 필기) + 자료 화면

### 학생 06 · 문항 목록 — `node-id=11-412` · `.../questions`
- **보여줄 것:** 문항 묶음 줄(제목 · 문항 수 · 상태: 풀기 전 / 완료 7/8)
- **누르면:** 줄 → 학생 07

### 학생 07 · 문제 풀기 — `node-id=11-444` · `.../questions/:setId/solve`
- **보여줄 것:** 제목 · "3 / 10" + 진행 막대 · 문제 · 보기 4개(고른 보기는 연한 분홍 + 레드 테두리)
- **누르면:** [제출] → 학생 08

### 학생 08 · 결과 — `node-id=11-484` · `.../questions/:setId/result`
- **보여줄 것:** 점수 "8 / 10 맞았어요" · 틀린 문제 줄(번호 · 다시 푼 횟수)
- **누르면:** [해설 볼래요] → 그 자리에서 해설 펼치기 / [다시 풀어볼래요] → 그 문제만 다시 풀기(학생 07), 다시 푼 횟수 +1 기록

### 학생 09 · 진단 결과 — `node-id=11-529` · `/student/diagnosis-result`
- **보여줄 것:** 듣기 · 읽기 · 종합 등급을 큰 글씨로(연한 파랑·노랑·초록 카드). 점수 대신 등급만 간단히

## 5. 아직 정해지지 않은 것

| 항목 | 상태 |
|---|---|
| 만든 자료 보기(교사), 만든 문항 보기(교사), 학생 개인 상세(교사) | 화면 없음 |
| 배포 버튼을 누른 뒤 이동할 화면 | 미정 |
| 로딩 화면("자료 만드는 중"), 빈 화면("아직 받은 자료가 없어요"), 오류 화면 | 화면 없음 |
