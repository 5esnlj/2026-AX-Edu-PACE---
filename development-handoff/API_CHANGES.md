# FE 소스 검토에 따른 API 1.1 수정

이번 검토 기준은 `가나다계단_프론트엔드.zip`의 실제 TypeScript/React 파일입니다. Figma 캔버스를 직접 열어 시각적으로 비교한 결과는 아닙니다. 원본은 별도 보존했고 수정본은 `frontend/`, API mock·명세는 `api/`에 있습니다.

## API에 반영하는 변경

| 항목 | 변경 | 이유 / DB 영향 |
|---|---|---|
| 교사·학생 대시보드 | `className: string` 추가 | 기존 FE의 클래스명을 고정 문자열 대신 표시. classes.name 조회 |
| 교사 대시보드 학생 행 | `diagnosticStatus: not_started / in_progress / completed` 추가 | 진단 전·진행 중·완료 구분. 미완료를 초급 미달로 표시하지 않음 |
| 학생별 자료 DTO | `unit: string` 추가 | 원본의 단원명을 전달. 임의의 단원 번호를 만들지 않음 |
| 학생 목록·교사 집계 | 비활성 학생 계정/소속 제외, 완료 진단만 결과 표시 | 명단·인원·활동 집계가 실제 활성 소속과 일치하도록 보완 |

기존 41개 API 동작을 유지합니다. `/student/classes/{id}/home`을 새로 만들지 않고 기존 `/classes/{id}/dashboard`에서 인증된 역할에 맞는 응답을 사용합니다. 기존 DB에 이번 화면 필드를 위한 테이블이나 컬럼을 추가하지 않습니다.

## 프론트에서 고치는 계약 차이

| 원본의 가정 | 수정된 연결 |
|---|---|
| 임시 URL을 화면 DTO로 바로 해석 | `/api/v1` 주소와 wire DTO → 화면 DTO 변환 함수 사용 |
| `c-302`, 교사/학생 이름을 고정 | `/auth/me`, `/classes`, 대시보드 응답에서 사용 |
| 자료 제작의 카드 = `/materials` | 교사 원본 목록 카드는 `/sources`; 학생별 전환본 목록은 `/materials`로 별도 구분 |
| 영어 교과·수준 코드와 한국어 타입 혼용 | 한 곳의 표에서 라벨 변환. 서버 판정을 FE에서 다시 채점하지 않음 |
| 초급·중급·고급만 요약/필터 | 초급 미달과 미진단 인원도 표시 |
| 교사에게 다른 교과 목록 표시 | 현재 담당 교과만 표시. 서버의 교과 권한도 유지 |
| 모든 과목을 합친 것처럼 보이는 듣기/읽기 | 선택한 영역과 그 영역의 듣기/읽기·종합을 표시 |
| `retryCount`를 틀린 문항 개수로 사용 | `currentWrongCount`와 실제 재풀이 횟수 구분 |
| 진행률 62%인데 완료 | 최초 제출 문항 수 / 전체 수로 계산. 풀이 중 별도 표시 |
| '오늘' 풀 문제 | 마감/일정이 없어 '아직 풀지 않은 문제'로 표시 |
| 성공 응답은 항상 JSON | 204 빈 본문 처리, 구조화된 오류, 인증된 쓰기의 CSRF 헤더 처리 |
| 오류가 나도 계속 불러오는 중 | 로딩·빈 결과·실패 상태 구분 |

## 바꾸지 않은 주요 계약

목록은 `{items, nextCursor}`; ID는 문자열; 세션은 HttpOnly 쿠키; 쓰기는 X-CSRF-Token; 생성/풀이 재전송은 Idempotency-Key; 수정/검토/배포는 ETag와 If-Match입니다. 교사·학생 권한과 미배포/미완료 진단 접근 제한은 서버에서 검사합니다.

이번 FE 수정은 **세 화면의 조회 연결과 연동 확인용 로그인·클래스 선택**입니다. 미구현 생성·검토·배포·풀이 화면을 완성했다고 표시하지 않습니다. API 자체는 메모리 mock이며 실제 DB/Solar 연결은 다음 개발 단계입니다.
