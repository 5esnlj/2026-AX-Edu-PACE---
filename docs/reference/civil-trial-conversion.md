# 자료 변환 규칙 (학습 한국어 에이전트)

이 문서는 예시 자료(민사 재판, 사회 210~211쪽)를 변환할 때 따른 규칙입니다. 다른 교과 자료를 넣어도 같은 형식의 결과가 나오도록, 에이전트 프롬프트와 화면 구현의 기준으로 사용합니다.

- 변환 전 예시: `docs/civil-trial-source.pdf`
- 변환 후 화면: `public/convert/view.html` (앱 실행 후 `/convert/view.html`)
- 변환 후 데이터: `backend/app/l1/data/civil_trial_conversion.example.json`

---

## 1. 핵심 원칙

1. **원본을 알아볼 수 있어야 한다.** 지면 배치, 그림, 제목, 쪽 번호, 색 구성, 문장 순서는 바꾸지 않는다. 학생과 교사가 같은 자료를 보고 있다는 것을 바로 알 수 있어야 한다.
2. **문장을 새로 쓰지 않고 표현만 바꾼다.** 원문 문장 안의 어려운 구(phrase)만 쉬운 표현으로 교체한다.
3. **교과 개념어는 지우거나 바꾸지 않는다.** 원문의 굵은 용어(예: 민사 재판, 원고, 소송 대리인)는 그대로 두고, 모국어 병기와 뜻풀이만 붙인다.
4. **분량이 늘어나는 지원은 펼침(토글)으로 넣는다.** 쉬운 설명, 그림, 문장틀은 기본으로 접혀 있고 학생이 눌러야 열린다.
5. **바꾼 부분은 언제든 원문으로 확인할 수 있다.** 교체된 표현을 누르면 그 바로 아래에 원문 표현이 나타난다.

## 2. 처리 순서

| 단계 | 처리 | 결과 |
|---|---|---|
| ① 추출 | PDF에서 텍스트, 그림, 위치를 추출 (그림은 분석·변형하지 않음) | 쪽별 블록 목록 |
| ② 블록 분류 | 각 텍스트를 아래 3장의 블록 유형으로 분류 | 블록 + 유형 |
| ③ 개념어 표시 | 원문의 굵은 글씨 + 교과 용어 대역표의 원어를 찾아 `[[용어]]`로 표시 | 개념어 목록 |
| ④ 위계 분류 | 개념어가 아닌 어려운 표현을 학습 한국어 위계(B, T1, T2, T3, C)로 분류 | 교체 후보 |
| ⑤ 수준별 교체 | 학생 읽기 수준에 따라 4장 기준으로 교체 표현 생성 | swaps |
| ⑥ 펼침 내용 | 5장 기준으로 쉬운 설명, 그림, 문장틀 생성 | easy_explanation, visual |
| ⑦ 병기 | 개념어에 대역표의 모국어를 붙임 (대역표에 없으면 붙이지 않음) | terms.l1 |
| ⑧ 검증 | 7장 검증 규칙으로 자동 점검 | 통과 / 수정 |
| ⑨ 교사 검토 | 그룹 검토 화면에서 원문과 비교 후 승인 | 최종본 |

## 3. 블록 유형별 처리

| 블록 유형 | 예시 | 표현 교체 | 펼침 |
|---|---|---|---|
| 장·절 제목, 쪽 번호, 단원명 | "03 재판의 의미와 공정한 재판", "210" | 하지 않음 | 없음 |
| 본문 문단 | "민사 재판의 의미" 문단 | 함 | 쉬운 설명, 그림 |
| 도입 이야기·말풍선 | 요술 항아리 이야기 | 함 (짧게) | 없음 |
| 학습 목표 | "…설명할 수 있다." | 함 | 없음 |
| 법 조문·인용문·출처 | 민사소송법 제87조, "— 전래 동화…" | 하지 않음 (원문 고정) | 쉬운 설명만 |
| 그림 설명·용어 풀이(✱) | "민사 법정 …", "✱ 소장 …" | 함 | 없음 |
| 과정 카드 | 한눈에 보기 ①~⑤ | 카드 설명문만 함, 카드 제목은 유지 | 없음 |
| 활동·문항 | 1~3번 활동 | 발문만 함 | 문장틀, 선택지 |

## 4. 수준별 교체 기준 (읽기 수준 6단계)

설계안의 '학습 한국어 위계별 재구성 규칙'을 표현 단위로 적용한다.

| 읽기 수준 | 교체 대상 | 교체 방식 | 문장당 교체 수 |
|---|---|---|---|
| 1 시작, 2 초기 | 생활 한국어(B)를 넘는 표현 대부분: 교실 어휘(T1), 사고도구 어휘(T2), 한자어 동사구, 법률·행정 표현 | 하위 위계의 고빈도 표현으로 교체 ("소송을 제기한 사람" → "법원에 먼저 재판을 부탁한 사람") | 최대 3개 |
| 3 발달, 4 확장 | 사고도구 어휘(T2) 중 어려운 것, 긴 한자어 구 | 같은 뜻의 쉬운 표현으로 교체 ("법률 지식이 부족하여" → "법을 잘 몰라서") | 최대 2개 |
| 5 연결, 6 도달 | 거의 교체하지 않음 | 필요할 때만 괄호 부연으로 정교화 ("당사자" → "당사자(재판을 직접 하는 원고나 피고)") | 최대 1개 |

교체 표현 작성 규칙
- 원문의 조사·어미 흐름이 그대로 이어지게 쓴다. 교체 후 문장을 읽었을 때 어색하지 않아야 한다.
- 교체 표현은 원래 표현 길이의 2배를 넘지 않는다.
- 문체는 원문을 따른다 (원문이 "-다"체면 교체 표현도 "-다"체).
- 같은 표현이 문서에 여러 번 나오면 같은 교체 표현을 쓴다.
- 생활 한국어(B) 수준 표현과 교과 개념어(C)는 교체하지 않는다.

## 5. 펼침 내용 생성 기준

| 펼침 | 생성 조건 | 내용 규칙 | 대상 수준 |
|---|---|---|---|
| 쉬운 설명 | 문단에 개념어 정의가 2개 이상 있거나, 법 조문처럼 원문을 바꿀 수 없는 블록 | 개념어는 그대로 쓰고 관계를 짧은 문장으로 풀이. 수준 1~2는 "-요"체 3~5문장, 수준 3~4는 "-다"체 1~3문장 또는 번호 목록 | 1~4 (법 조문은 1~6) |
| 그림으로 보기 | 인물·역할 관계, 절차·순서, 목록형 정보, 또는 수준 대비 모르는 단어가 많은 문단 | 흐름도, 관계도, 비교표, 계층도, 인과 도식 중 하나. 핵심 사실만, 배경·복잡한 데이터 제외 | 1~4 |
| 문장틀 | 서술형 활동 | 빈칸 2개 이내의 문장 1개 | 1~4 |
| 선택지 | 단답형 활동 | 원래 입력칸은 유지하고 아래에 보기 칩 추가 | 1~4 |

## 6. 모국어 병기·뜻풀이

- 병기 대상은 `[[용어]]`로 표시된 교과 개념어만이다.
- 모국어 표기는 **교과 용어 대역표의 대표어만** 쓴다. 대역표에 없으면 병기하지 않고 뜻풀이 화면에 "준비 중"으로 표시한다. 에이전트가 번역어를 새로 만들지 않는다.
- 병기는 용어 바로 아래 작은 글씨로 붙인다 (지면 형식을 바꾸지 않기 위해).
- 용어를 누르면 쉬운 뜻, 모국어, "모르는 단어로 저장" 버튼이 열린다.
- 활동·문항에서 정답이 되는 용어에는 병기와 뜻풀이를 붙이지 않는다 (정답 단서 방지).

## 6-1. 학생이 직접 단어 찾기 (드래그 검색)

변환에서 빠진 어려운 말이 있을 수 있으므로, 학생이 스스로 모르는 말을 골라 찾고 저장할 수 있게 한다.

**동작**
1. 학생이 지면의 글자를 드래그(모바일은 길게 눌러 선택)한다.
2. 선택 영역 바로 아래에 "단어 찾기" 버튼이 뜬다. (지면 밖, 입력칸, 줄바꿈이 포함된 선택, 20자 초과 선택에서는 뜨지 않음)
3. 버튼을 누르면 결과 시트가 열린다: 표제어, 쉬운 뜻, 학생 모국어, "모르는 단어로 저장".
4. 저장한 단어는 단어장에 "직접 찾기"로 표시되어 쌓이고, 교사 리포트의 학습 트래킹(추가로 모르는 단어) 자료가 된다.

**표제어 찾기 순서**
1. 선택한 말 그대로 교과 용어(`terms`) → 일반 낱말 사전에서 찾는다.
2. 없으면 끝의 조사·어미(은/는/이/가/을/를/의/에/에서/으로/와/과/도/만, 하여/하고/하며/한/할/하는/하던/한다/했다 등)를 떼고 다시 찾는다.
3. 없으면 선택한 말이 표제어로 시작하는지 확인한다 (예: "법률 지식이" → "법률").
4. 그래도 없으면 "아직 사전에 없는 말"로 안내하고, 뜻 없이도 저장할 수 있게 한다.

**사전 출처**
- 예시 화면에는 이 자료에 나오는 일반 낱말 35개의 시연용 소사전을 넣었다 (대역 검증 전).
- 실제 서비스에서는 소사전 대신 한국어 학습 사전 API와 AI 뜻풀이를 연결한다. AI 뜻풀이는 선택한 문장 맥락을 함께 보내 문맥에 맞는 뜻을 받고, 모국어는 대역표에 있으면 대역표 값을 우선한다.
- 교과 용어로 찾은 경우 "이 자료의 교과 용어예요"라고 표시한다.

**저장 데이터 (예시)**
```json
{ "student_id": "st2", "word": "제출", "easy": "서류나 물건을 내는 것",
  "l1": "topshirish", "how": "직접 찾기", "material": "민사 재판 210-211", "selected_text": "제출하며" }
```
- `how`: "용어 누르기"(개념어 팝업에서 저장) 또는 "직접 찾기"(드래그 검색에서 저장)
- `selected_text`: 학생이 실제로 선택한 형태. 교사 리포트에서 어떤 문맥에서 막혔는지 확인하는 데 쓴다.

## 7. 검증 규칙 (자동 점검)

| 항목 | 기준 | 실패 시 |
|---|---|---|
| 원문 일치 | 모든 `swap.from`이 해당 블록 원문에 그대로 있는 부분 문자열 | 해당 교체 삭제 |
| 개념어 보호 | `swap.from`이 `[[용어]]`와 겹치지 않음 | 해당 교체 삭제 |
| 교체 수 | 4장의 문장당 최대 교체 수 이내 | 위계가 높은 것부터 남기고 삭제 |
| 길이 | `swap.to` 길이 ≤ `swap.from` 길이 × 2 | 다시 생성 |
| 고정 블록 | 제목, 쪽 번호, 법 조문, 인용, 출처에 교체 없음 | 해당 교체 삭제 |
| 병기 출처 | 모든 병기 값이 대역표 대표어와 일치 | 병기 삭제 |
| 정답 보호 | 활동의 정답 용어에 병기·뜻풀이 없음 | 병기·뜻풀이 삭제 |

## 8. 화면 표시 규칙

- 지면은 원본 색과 배치를 그대로 쓰고, 서비스 색(teal)은 설정 막대와 도구 막대에만 쓴다.
- 교체된 표현: 옅은 청록 밑줄 띠. 누르면 그 표현 **바로 아래**에 원문 표현을 작은 회색 글씨로 표시 (앞에 "원래:" 같은 말은 붙이지 않음). 다시 누르면 닫힘.
- 펼침 버튼: 문단 바로 아래에 작은 알약형 버튼("쉬운 설명", "그림으로 보기", "문장틀"). 기본은 접힘.
- 상단 토글 3개
  - 바뀐 표현 표시: 끄면 밑줄 없이 교체 표현만 자연스럽게 보임
  - 모국어 병기: 끄면 용어 아래 모국어 숨김
  - 원본 그대로 보기: 켜면 모든 교체·병기·펼침이 사라지고 원문만 보임
- 하단 도구 막대: 듣기(TTS), 글자 작게·크게, 단어장(모르는 단어 개수 표시)
- 드래그 선택 시 "단어 찾기" 버튼 (6-1장)

## 9. 데이터 형식

`03_변환후_데이터_민사재판.json` 기준.

```json
{
  "material": { "subject": "사회", "unit": "…", "pages": [210, 211] },
  "terms": [
    { "term": "원고", "easy": "법원에 먼저 재판을 부탁한 사람",
      "l1": { "zh": "原告", "uz": "da’vogar", "mn": "нэхэмжлэгч" }, "l1_verified": false }
  ],
  "blocks": [
    { "id": "c",
      "original": "[[민사 재판]]은 개인 사이의 다툼을 … 소송을 제기한 사람을 [[원고]] …",
      "swaps": [
        { "from": "소송을 제기한 사람", "to": "법원에 먼저 재판을 부탁한 사람", "levels": [2, 4] }
      ],
      "easy_explanation": { "2": "두 사람이 다툴 때 …", "4": "민사 재판에는 …" },
      "visual": { "type": "relationship", "show_for_levels": [1, 2, 3, 4] } }
  ]
}
```

- `original`은 원문 그대로이며, `[[ ]]`는 원문의 굵은 개념어 표시다.
- `swaps.levels`는 그 교체를 적용할 읽기 수준이다. 예시에는 2, 4, 5 수준 학생만 있으므로, 실제 구현에서는 수준 1~6에 맞춰 범위로 생성한다 (예: 1~2 / 3~4 / 5~6).
- 화면은 `original`에서 `from`을 찾아 `to`로 바꿔 보여 주고, 누르면 `from`을 아래에 표시한다.

## 10. 에이전트 프롬프트 초안 (자료 1개 블록 단위)

```
당신은 중학교 교과 자료를 다문화 학생의 학습 한국어 수준에 맞춰 변환하는 도우미입니다.
입력: 블록 원문(굵은 개념어는 [[ ]] 표시), 블록 유형, 학생 읽기 수준(1~6), 교과 용어 대역표.

규칙
1. 문장을 새로 쓰지 말고, 원문 속 어려운 구만 쉬운 표현으로 바꾼다.
2. [[ ]] 안의 개념어, 제목, 법 조문, 인용, 출처는 바꾸지 않는다.
3. 수준 1~2는 문장당 최대 3개, 3~4는 2개, 5~6은 1개까지 바꾼다. 5~6은 괄호 부연만 쓴다.
4. 교체 표현은 원문 문체와 조사·어미에 맞추고, 원래 표현 길이의 2배를 넘지 않는다.
5. from은 원문에 그대로 있는 부분 문자열이어야 한다.
6. 개념어 정의가 2개 이상이거나 고정 블록이면, 수준 1~4에 한해 쉬운 설명을 만든다.
```
