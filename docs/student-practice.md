# 학습자료 기반 AI 문제 만들기

학생의 **이해 확인 → AI 문제 만들기**에서 사용합니다. 한국어 진단 전에도 이용할 수 있으며, 학생의 언어·진단 정보가 바뀌었다고 기존 학습자료를 다시 만들 필요는 없습니다.

1. **선생님이 보낸 자료**, **내가 만든 자료**, **직접 글 입력** 중에서 자료를 고릅니다.
2. **T/F(O/X)** 또는 **4지선다**를 선택합니다.
3. 자료를 읽었고 문제를 풀겠다는 확인란을 선택한 뒤 **AI 문제 만들기**를 누릅니다.
4. 자료에서 확인할 수 있는 내용으로 최대 3문제를 만듭니다. 답안을 제출하면 정답과 해설을 볼 수 있습니다.
5. 생성한 문제와 풀이 결과는 **이해 확인** 목록에 저장됩니다. 다른 형식으로 다시 생성해도 이전 문제와 기록을 덮어쓰지 않습니다.

수업 자료 읽기 화면에서도 문제 만들기로 이동할 수 있습니다. 학생이 직접 재구성한 자료에서는 학습 완료 후 같은 생성 기능을 사용합니다. 기존 이해 확인 문제와 주관식 풀이 기록은 계속 열람할 수 있지만, 새 문제의 형식은 T/F와 4지선다만 제공합니다.

## AI 연결

기존 `.env`의 `IEUM_AGENT_PROVIDER=solar`, `UPSTAGE_API_KEY`, `SOLAR_MODEL`을 사용합니다. 문제 생성 버튼을 누를 때만 모델을 호출합니다. 학습자료와 필요한 학습 지원 정보가 모델에 전달되며 API 키는 서버에서만 사용하고, 정답은 제출 전 학생 화면에 노출하지 않습니다.

진단 결과가 있으면 표현 수준을 조정하는 참고 정보로 사용하고, 없으면 쉬운 한국어로 출제합니다. 문제 정답률로 진단 수준을 자동 변경하지 않습니다. 문항의 내용·선택지·근거는 교사 검토가 필요할 수 있습니다.

`demo` 설정에서는 화면 흐름을 확인할 수 있는 규칙 기반 예시 문제를 제공합니다. 실제 AI 생성과 구분해 표시합니다. Solar 연결 실패 시 데모 문제로 자동 대체하지 않으며, 연결 오류를 안내합니다. 환경 설정을 바꾼 뒤에는 서버를 다시 실행해야 합니다.

## 구현

- `POST /api/student-practice`: 자료 권한 확인 → 원문 사본 구성 → 선택 형식으로 생성 → 결과 검증 → 개인 문제 저장
- `GET /api/student-practice`, `GET /api/student-practice/{id}`: 본인의 생성 이력·문제 조회
- `POST /api/student-practice/{id}/submit`: 서버 채점 후 정답·해설 공개

문제 생성에는 학습 완료·풀이 선택 확인이 필요합니다. 서버는 다른 학생의 자료, 배포되지 않은 교사 자료, 선택한 형식과 다른 모델 응답, 존재하지 않는 근거 문장 등을 거부합니다. 자료가 생성된 시점의 진단과 현재 진단이 다르다는 이유만으로 생성을 차단하지 않습니다.
