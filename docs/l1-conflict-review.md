## 충돌·결정 필요 목록

### A. 시연 결과에 직접 영향 (우선 결정)

**A1. 재구성 단위: 문장 다시 쓰기 vs 표현만 교체**
- 팀원: `key_sentences.rewritten`에 문장 전체를 다시 쓴 결과
- 시연: 원문 지면을 유지하고 어려운 구만 교체 (`from → to`)
- 시연 처리: 출력에 `key_sentences.swaps: [{from, to, tier}]`를 추가하고, `rewritten`은 원문에 swaps를 적용한 결과로 채움
- 결정 필요: `swaps` 필드를 공식 출력에 추가할지, 프롬프트에 "원문의 부분 문자열만 교체" 규칙을 넣을지

**A2. 교과 개념어(3단계)가 들어간 표현의 교체**
- 팀원 규칙: 3단계 교과 적응 한국어는 삭제·대체하지 않고 상세화만
- 시연: "소송을 제기한 사람 → 법원에 먼저 재판을 부탁한 사람"처럼 '소송·제기·당사자'가 들어간 정의문 표현을 교체함 (읽기 2·4 그룹)
- 시연 처리: 해당 교체에 "교사 확인 필요" 표시 + 경고 + 확인 질문
- 결정 필요: ① 팀원 규칙대로 원문 유지 + 괄호 설명으로 바꿀지 ② 정의문 속 표현은 예외로 교체를 허용할지

**A3. 모국어 번역 출처: 어휘 사전이 비어 있음**
- 팀원: `vocabulary_lexicon.json`의 `entries`가 비어 있고, "확인된 번역만, 없으면 빈 값" 규칙
- 결과: 지금 그대로 실행하면 모국어 병기가 하나도 나오지 않음
- 시연 처리: 시연용 대역을 넣고 `translation_status: "review"`(검증 전)로 표시
- 결정 필요: 대역표 작성 담당과 일정, 사전 항목 형식 (B1 참고)

**A4. 위계별 숙달도 기준선**
- 팀원: "진단 단계까지 유지, 상위 단계만 조정" (숙달 단계 수치 기준 미정)
- 시연: M6 유지 · M4~5 상세화 · M3 이하 단순화로 임시 설정
- 결정 필요: 유지/상세화/단순화를 가르는 숙달 단계 값

**A5. 처리 단위: 학생 1명 vs 그룹**
- 팀원 워크플로: 학습자 1명 프로필로 1회 실행
- 시연: 읽기 수준 + 모국어가 같은 학생을 한 그룹으로 묶어 그룹당 1회
- 결정 필요: 그룹 대표 프로필을 어떻게 정할지 (가장 낮은 학생 기준 등), 아니면 학생별 실행 후 같은 결과를 묶을지

### B. 데이터 형식

**B1. 어휘 사전 항목 형식 (오역 판독과 연결)**
- 팀원: 항목 형식 미정
- 제안: 대표어·허용 변이·혼동사전을 함께 저장해야 오역 판독이 가능함
```json
{ "term": "원고", "tier": "3", "category": "curriculum_adapted",
  "simple_meaning": "법원에 먼저 재판을 부탁한 사람",
  "translations": { "zh": { "preferred": "原告", "variants": [], "confusions": ["原稿"] } },
  "verified": false }
```

**B2. 출력 형식 불일치 (팀원 파일 내부)**
- `agent_system_prompt.md`: `key_sentences`, `simple_meaning` (snake_case)
- `agent_workflow.py`의 `OUTPUT_CONTRACT`: `sentences`, `simpleMeaning` (camelCase)
- 시연 처리: 시스템 프롬프트 형식을 따름
- 결정 필요: 파이썬 `OUTPUT_CONTRACT`를 프롬프트 형식으로 통일

**B3. 위계 코드 이중 표기**
- `learners.json`: B, T1, T2, T3, C / `reconstruction_rules.json`: 1, 2-1, 2-2, 2-3, 3
- 시연 처리: B=1, T1=2-1, T2=2-2, T3=2-3, C=3 대응표로 변환
- 결정 필요: 대응표를 규칙 파일에 명시

**B4. 언어 표기**
- 프로필: "중국어" (한국어 이름) / 화면·사전: zh, uz, mn (언어 코드)
- 결정 필요: 프로필에 `native_language_code` 추가 또는 변환표 공유

**B5. 교사 수정 형식 (`teacher_edits`)**
- 팀원: 수정된 JSON 파일 전체를 다시 넣는 방식 (콘솔)
- 시연: 표현 단위로 "원문으로 되돌리기 / 직접 고치기", 수정하면 해당 그룹 승인 해제
- 제안 형식: `{"learner_or_group":"l2", "block":"c", "from":"양측의", "action":"revert" | "edit", "to":"두 사람의"}`

**B6. 학생이 직접 찾은 단어**
- 팀원: `knowledge_state`가 known / unknown / unmarked 세 가지
- 시연: 드래그 검색으로 저장한 단어는 `how: "직접 찾기"`, `selected_text`(선택한 형태)를 추가로 저장
- 결정 필요: `vocabulary_state`에 이 두 필드 추가

### C. 기능 범위

**C1. 오역 판독 단계 없음**
- 팀원 워크플로는 재구성까지만 있음
- 시연: 별도 "오역 판독" 탭 (대역표·혼동사전 대조, 판정 S1~S3, 이유·올바른 말·추정 원인)
- 결정 필요: 워크플로에 판독 단계(별도 함수 또는 프롬프트) 추가

**C2. 평가 공정성 규칙 없음**
- 활동·문항에서 정답이 되는 용어는 병기·뜻풀이 금지 규칙이 팀원 프롬프트에 없음
- 결정 필요: 프롬프트 판단 원칙에 추가

**C3. 문장당 교체 수 상한 없음**
- 시연 규칙: 읽기 1~2는 문장당 최대 3개, 3~4는 2개, 5~6은 1개
- 결정 필요: 프롬프트 품질 확인 항목에 추가할지

**C4. 시각 자료 기본 표시**
- 팀원: `visible_by_default` 기본값 true
- 시연: 지면 형식을 지키려고 쉬운 설명·그림을 기본 접힘으로 둠
- 결정 필요: 기본값을 읽기 수준별로 정할지 (예: 읽기 1~2만 펼침)

**C5. 시각 자료 종류**
- 팀원 규칙: 순서도·목록·비교표·벤다이어그램
- 시연: 인물 관계도를 사용 (`kind: "other"`로 출력)
- 결정 필요: 관계도를 허용 종류에 추가할지

**C6. 필기 도구**
- 팀원: `handwriting_supported_by_host` 항목 있음
- 시연: 필기 도구 미구현 (도구 막대에 듣기·확대·단어장만)
- 결정 필요: 시연에 넣을지

### D. 코드 수정 제안 (`agent_workflow.py`)

| 항목 | 내용 |
|---|---|
| D1. 절차 신호 탐지 | `source_signals` 정규식의 `\b`가 한국어 조사와 맞지 않아 "순서대로", "과정에서"를 놓침. `\b` 제거 필요 |
| D2. PDF 배치 정보 | `pypdf.extract_text`는 위치를 버림. 원본 지면 유지 화면에는 블록 위치가 필요해 PyMuPDF(`page.get_text("dict")`) 등 검토 |
| D3. 모델 연결부 | 어댑터가 없으면 `plan_only`만 반환. Gemini 어댑터 구현 필요 (API 키는 서버 보관) |
| D4. 학습자 데이터 | `learners.json`에 학생 A(중국어) 1명뿐. 시연용으로 student_b(몽골어, 종합 4), student_c(우즈베크어, 종합 2)를 같은 형식으로 임시 추가함. 실제 값 확인 필요 |
| D5. 표시 이름 | `display_name: "학생 A"`와 시연 이름(리나) 불일치. 시연 이름 사용 여부 결정 |
