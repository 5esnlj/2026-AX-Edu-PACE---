# 변환 예시 화면 (민사 재판)

원본 지면을 유지한 채 학생 수준별로 표현만 바꾸는 재구성 시연 화면입니다. React 앱과 별개인 정적 페이지라 서버·DB 없이 동작합니다.

## 여는 법

- 앱 실행(`npm run dev`) 후 **자료실** 위쪽의 **변환 예시 (민사 재판)** 버튼
- 직접 주소: `/convert/view.html?view=make` (교사 · 자료 재구성), `?view=check` (오역 찾기), `?view=student&sid=a&own=1` (학생 화면, sid = a 리나 · b 아지즈 · c 딜노자 · d 바트볼드)

## 시연 순서

1. 자료 재구성 → 예시 자료(민사 재판) 사용 → 자료 재구성 시작
2. 그룹 탭(아지즈·바트볼드·딜노자·리나)별로 밑줄·설명·쉬운 표현·그림을 펼쳐 확인, '수정하기'로 고치기, 지면 글자를 드래그해 상호작용 추가
3. 그룹마다 '이 그룹 승인' → '학생에게 보내기'
4. 오역 찾기 → 변환 자료 병기 점검(시드 오역 4건) / 외부 번역본 검사(5개 언어)
5. 학생 화면: 밑줄 표현·용어 누르기, 듣기·크게·필기·단어장, 드래그로 단어 찾기

## 앱 안의 수업 자료 화면 (2026-10-31 추가)

민사 재판 예시로 만든 자료(원본 PDF가 `/examples/civil-trial-source.pdf`)는 수업 자료 화면에서 위 시연 화면과 같은 방식으로 보여요. 디자인은 가나다 계단, 내용 구성은 변환 예시를 따릅니다.

- **교사 · 검토:** 학생 탭마다 원본 지면이 그대로 나오고, 밑줄·설명·쉬운 표현·그림을 펼쳐 '수정하기'·원문으로 되돌리기. 지면 글자를 드래그하면 밑줄·설명·시각 자료 추가. 고치면 그 학생의 검토 확인이 풀려요. 문장별 세부 편집(L1)은 '에이전트 판단 근거' 안에 있어요.
- **학생 · 읽기:** 원본 지면 + 밑줄 표현(누르면 원래 표현) + 교과 개념어 '설명' + 모국어 병기(누르면 뜻·듣기·단어 저장) + 쉬운 표현·그림 펼침 + 드래그로 단어 찾기. 크게·작게, 원본 보기, 소리 내어 읽기는 기존 버튼을 그대로 써요.
- **수준:** 학생의 읽기 수준으로 재구성본을 골라요(1~2 / 3~4 / 5~6). 진단 전(0)이면 3~4용.
- **병기 언어:** 중국어·우즈베크어·몽골어·베트남어·영어·벵골어. 원고·피고·소송 대리인은 팀 공식 대역표 값을 써요. 베트남어·영어·벵골어는 시연용 값으로 원어민 확인 전이에요.
- **저장:** 교사가 고친 내용은 지금은 이 브라우저에 저장돼요(`ganada-convert:자료id:학생id`). 같은 브라우저에서 학생으로 바꿔 보면 반영돼요. 서버 저장은 후속 작업이에요.
- **코드:** `src/convert/engine.ts`(지면 그리기·상호작용), `src/convert/ConvertPage.tsx`(React 연결), `src/convert/convert.css`, 그림 `public/convert/img/`
