# 변환 예시 화면 (민사 재판)

원본 지면을 유지한 채 학생 수준별로 표현만 바꾸는 재구성 시연 화면입니다. React 앱과 별개인 정적 페이지라 서버·DB 없이 동작합니다.

## 여는 법

- 앱 실행(`npm run dev`) 후 **자료실** 위쪽의 **변환 예시 (민사 재판)** 버튼
- 직접 주소: `/convert/view.html?view=make` (교사 · 자료 재구성), `?view=check` (오역 찾기), `?view=student&sid=a&own=1` (학생 화면, sid = a 리나 · b 아지즈 · c 딜노자 · d 바트볼드)

## 시연 순서

1. 자료 재구성 → 예시 자료(민사 재판) 사용 → 자료 재구성 시작
2. 그룹 탭(아지즈·바트볼드·딜노자·리나)별로 밑줄·설명·쉬운 표현·그림을 펼쳐 확인, '수정하기'로 고치기, 지면 글자를 드래그해 상호작용 추가
3. 그룹마다 '이 그룹 승인' → '학생에게 보내기'
4. 오역 찾기 → 변환 자료 병기 점검(시드 오역 4건) / 외부 번역본 검사(5개 언어)
5. 학생 화면: 밑줄 표현·용어 누르기, 듣기·크게·필기·단어장, 드래그로 단어 찾기

## 앱 안의 수업 자료 화면 (2026-10-31 추가)

민사 재판 예시로 만든 자료(원본 PDF가 `/examples/civil-trial-source.pdf`)는 **원본 지면 변환 예시 보기**를 펼치면 지면 기반의 시연 화면을 사용할 수 있습니다.

- **교사 · 검토:** 기본 화면의 문장별 편집과 ‘검토 내용 저장’은 서버에 저장되며 학생에게 배포됩니다. 별도의 지면 예시에서는 밑줄·설명·쉬운 표현·그림을 펼쳐 수정하거나 지면 글자를 드래그해 지원을 추가할 수 있습니다.
- **학생 · 읽기:** 선생님이 검토해 저장한 글과 지원 내용이 기본 본문입니다. 원본 지면 예시는 별도로 펼쳐 볼 수 있습니다. 예시의 단어 저장은 기존 단어장·메모 저장 버튼으로 보관합니다.
- **수준:** 지면 예시는 읽기 진단 결과가 있을 때만 해당 구간(1~2 / 3~4 / 5~6)을 적용합니다. 진단 전(0)에는 중간 수준을 임의로 정하지 않고 원본 PDF 링크를 제공합니다.
- **병기 언어:** 중국어·우즈베크어·몽골어·베트남어·영어·벵골어. 원고·피고·소송 대리인은 팀 공식 대역표 값을 씁니다. 대역은 원어민 확인 전입니다.
- **예시 저장:** 지면 예시 안의 수정은 이 브라우저에만 저장됩니다(`ganada-convert:자료id:학생id`). 서버의 검토본과 자동 동기화되지 않습니다. 실제 배포 내용은 기본 문장별 편집에서 수정해야 합니다.
- **코드:** `src/convert/engine.ts`(지면 그리기·상호작용), `src/convert/ConvertPage.tsx`(React 연결), `src/convert/convert.css`, 그림 `public/convert/img/`
