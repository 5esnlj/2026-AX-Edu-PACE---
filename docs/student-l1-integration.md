# 학생용 자료 재구성과 이해 확인

첨부 `L1 자료 재구성+이해 확인 문항 학생용.zip`의 학생용 워크플로우, 재구성 프롬프트, 평가 프롬프트와 공정성 규칙을 웹앱에 통합했습니다. 첨부 코드는 모델을 직접 호출하지 않는 워크플로우이므로, 서버의 Solar 연결과 데이터 저장·학생 화면을 추가했습니다.

## 사용 순서

1. 학생으로 입장해 **나의 수업 자료 → 내 자료 재구성하기**를 누릅니다.
2. 제목·교과를 입력하고 수업 원문을 붙여넣거나 텍스트가 포함된 PDF를 업로드합니다. 추출된 원문을 확인하고 수정할 수 있습니다.
3. **나에게 맞게 재구성**을 누릅니다. 학생을 다시 선택하거나 수준을 직접 입력하지 않습니다. 로그인한 학생의 현재 6수준 진단 결과를 서버에서 가져옵니다.
4. 재구성 문장, 핵심어 설명, 필요한 시각 자료를 읽습니다. 원문과 비교할 수 있습니다.
5. **학습 완료**를 누른 뒤, 원하는 경우 **이해 확인 문항을 풀어 볼래요**를 선택하고 **이해 확인 문항 만들기**를 누릅니다.
6. 답안을 제출하면 정답과 해설을 확인할 수 있습니다. 자료·학습 완료·문항·응답은 저장되므로 다음에 다시 열 수 있습니다.

학생 A에는 첨부 PDF의 6수준 진단이 등록되어 있어 전체 흐름을 바로 확인할 수 있습니다. 진단 전 학생은 수준을 추정하지 않고 원문을 보존하며, 이해 확인 문항 생성에는 진단 정보가 필요합니다. 한국어 자가 점검과 필요한 교사 채점을 마친 뒤 새 자료를 만들어 주세요.

## 첨부 코드에서 반영한 기준

- 진단 결과를 근거로 지원하며, 기존 4단계나 첨부 예시 인물을 현재 학생의 진단으로 사용하지 않습니다.
- 상세 설명을 우선하고 핵심 교과 개념어를 유지합니다. 모국어가 확인되지 않으면 임의로 언어를 추정하거나 번역하지 않습니다.
- 원문에 근거한 문장 ID를 사용하고, 실제 학습한 자료를 문항 생성에 전달합니다.
- 학습 완료와 학생의 선택을 모두 확인한 뒤 문항을 생성합니다. 서버에서도 이 조건을 검사합니다.
- O/X, 간단한 주관식, 4지선다 형식을 지원합니다. 생성된 문항의 근거와 공정성 검토 항목을 검사합니다.
- 정답·허용 답안·해설은 제출 전 API 응답에서도 제외합니다. 이 기능의 풀이 결과는 한국어 진단 수준을 자동 변경하지 않습니다.
- 학생이 만든 자료는 해당 학생만 조회할 수 있으며 교사가 배포한 자료와 별도로 보관합니다.

## 데모와 실제 생성

`IEUM_AGENT_PROVIDER=solar`이면 기존 서버의 `UPSTAGE_API_KEY`, `SOLAR_MODEL` 설정으로 재구성 및 문항 생성을 요청합니다. 자료 원문과 이름·ID를 제외한 학습 프로필이 모델에 전달됩니다. 키는 브라우저에 전달하지 않습니다. Solar 오류 시 데모 결과로 조용히 대체하지 않고 오류를 표시합니다.

`demo` 모드에서는 원문을 보존하는 규칙 기반 자료와 자료의 문장을 확인하는 O/X 예시 문항을 제공합니다. 실제 수준별 AI 재구성이나 평가 정확도를 검증하는 용도로 사용하지 마세요. 화면에도 데모임을 표시합니다.

현재 PDF 입력은 텍스트 추출 방식입니다. 스캔본 OCR은 지원하지 않으며 텍스트를 붙여넣도록 안내합니다. 시각 자료는 텍스트 기반 구조로 표시하고 이미지를 자동 생성하지 않습니다. 주관식 자동 채점은 생성된 허용 답안과의 일치를 사용하므로 모든 동의 표현을 이해하는 의미 채점은 아닙니다.

## Windows 적용

프로젝트를 연 VS Code 터미널에서 실행 중인 서버를 `Ctrl+C`로 종료하고, 업데이트한 코드에서 다음 명령을 실행합니다.

```powershell
npm.cmd install
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
npm.cmd run dev
```

기존 DB를 지우지 마세요. 시작할 때 학생용 저장 구조가 추가됩니다. `.env`의 Solar 설정을 바꿨다면 서버를 재시작해야 합니다. 실제 Solar 연결 문제는 [Solar 설정 안내](solar-setup.md)를 참고하세요.
